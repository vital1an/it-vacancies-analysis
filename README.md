# Анализ IT-вакансий

## Описание проекта
В рамках проекта выполнен анализ вакансий в Data-сфере (Data Analyst, Data Engineer, Data Scientist / ML Engineer) с целью определения структуры рынка труда, востребованных навыков и требований к опыту работы.

Проект выполнен в учебных и портфельных целях и демонстрирует аналитическую работу с реальными данными: от первичной очистки и подготовки до исследовательского анализа и формирования выводов.

## Цель проекта
- Проанализировать распределение Data-вакансий по направлениям
- Оценить географическую концентрацию вакансий
- Изучить требования работодателей к уровню опыта (Junior / Middle / Senior)
- Проанализировать уровень и структуру заработных плат

## Данные
Использован датасет с вакансиями в IT-сфере, содержащий:
- название вакансии  
- город  
- опыт работы  
- ключевые навыки
- диапазон заработной платы
- валюта заработной платы
- описание вакансии
- дата публикации вакансии

Анализ охватывает вакансии, опубликованные в период сентябрь – октябрь 2023 года.

### Источник данных
Данные получены с платформы **Kaggle**: https://www.kaggle.com/datasets/ilyazawilsiv/it-vacancies-from-headhunter-website/data

В связи с большим размером датасета и условиями распространения исходный файл **не размещён в репозитории**.

Для воспроизведения анализа необходимо:
1. Скачать датасет с Kaggle  
2. Поместить файл `IT_vacancies.csv` в папку `data`  
3. Запустить ноутбук `it_vacancies_analysis.ipynb`

## Этапы работы
1. Загрузка и первичный анализ данных
2. Нормализация названий Data-специальностей 
3. Очистка и подготовка данных  
4. Категоризация опыта работы (Junior / Middle / Senior)
5. Конвертация заработных плат в рубли
6. Анализ распределения вакансий по ролям, регионам и формату работы  
7. Анализ заработных плат по направлениям и грейдам  
8. Анализ востребованных навыков и пар навыков
9. Формирование итоговых выводов

## Используемые технологии
- Python  
- Pandas

## Основные результаты
1. Около 47% всех Data-вакансий приходится на роль Data Analyst, остальные вакансии распределены между Data Engineer и ML/Data Scientist
2. Рынок ориентирован преимущественно на специалистов уровня Middle и Senior. На Junior приходится менее 5% вакансий
3. Среди Junior-вакансий удалённый формат работы предлагается менее чем в 14% случаев, что ниже среднего уровня по рынку
4. Data Engineer и ML/Data Scientist на уровнях Middle и Senior демонстрируют более высокие медианные зарплаты по сравнению с Data Analyst
5. Наиболее востребованные навыки в Data-сфере: Python, SQL, Machine Learning
6. Самые распространённые комбинации навыков: Python + SQL, SQL + анализ данных, Machine Learning + Python

## Ограничения анализа
1. Анализ выполнен на основе данных одного источника и не полностью отражает рынок IT-вакансий
2. В части вакансий отсутствует информация о ключевых навыках
3. Анализ заработных плат ограничен неполнотой данных о зарплатах
4. Учитывать динамику рынка во времени не позволяет короткий период времени, который охватывают данные
